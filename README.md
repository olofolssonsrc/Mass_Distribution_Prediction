Inverse problem solver concept for determining point mass locations and size given a path affected by gravity of a negligele mass. The approach is integrating the path and using finite difference acceleration vectors create probability fields. Gradiant decent based approach to find exact location.
  The project also includes nbody simulation to generate paths, javascript&html interface for visualising the components. The project was expirimental and ment mostly as a exersice for the course scientific machine learning at tu delft.
